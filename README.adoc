= modern-gitops-stack-module-kafka-ui
// Document attributes to replace along the document

:original-repo-url: https://github.com/provectus/kafka-ui-charts

A https://modern-gitops-stack.io[Modern GitOps Stack] module to deploy Kafka UI, a web interface to browse brokers, topics, consumer groups and messages.

The kafka-ui chart used by this module is shipped in this repository as well, in order to avoid any unwanted behaviors caused by unsupported versions.

|===
|Current Chart Version |Original Repository |Default Values
|*0.7.6* |https://github.com/provectus/kafka-ui-charts/tree/main/charts/kafka-ui[kafka-ui] |https://artifacthub.io/packages/helm/kafka-ui/kafka-ui/0.7.6?modal=values[`values.yaml`]
|===

== Usage

This module can be declared by adding the following block to your Terraform configuration:

[source,terraform]
----
module "kafka-ui" {
  source = "git::https://github.com/GersonRS/modern-gitops-stack-module-kafka-ui.git?ref=<RELEASE>"

  cluster_name      = local.cluster_name
  base_domain       = local.base_domain
  subdomain         = local.subdomain
  cluster_issuer    = local.cluster_issuer
  app_autosync      = local.app_autosync
  kafka_broker_name = "edh-kafka-bootstrap"

  dependency_ids = {
    strimzi = module.strimzi.id
    kafka   = module.kafka.id
  }
}
----

The application is deployed to the `observability` namespace.

== Technical Reference

=== Dependencies

==== `module.strimzi.id`

Kafka UI connects to the Strimzi-managed Kafka cluster.

==== `module.kafka.id`

The Kafka cluster must exist before Kafka UI starts.

=== Optional Inputs

The following input variables are optional (have default values):

==== [[input_subdomain]] <<input_subdomain,subdomain>>

Description: Subdomain of the cluster. Value used for the ingress' URL of the application.

Type: `string`

Default: `"apps"`

==== [[input_argocd_project]] <<input_argocd_project,argocd_project>>

Description: Name of the Argo CD AppProject where the Application should be created. If not set, the Application will be created in a new AppProject only for this Application.

Type: `string`

Default: `null`

==== [[input_argocd_labels]] <<input_argocd_labels,argocd_labels>>

Description: Labels to attach to the Argo CD Application resource.

Type: `map(string)`

Default: `{}`

==== [[input_destination_cluster]] <<input_destination_cluster,destination_cluster>>

Description: Destination cluster where the application should be deployed.

Type: `string`

Default: `"in-cluster"`

==== [[input_target_revision]] <<input_target_revision,target_revision>>

Description: Override of target revision of the application chart.

Type: `string`

Default: `"v2.0.3"`

==== [[input_cluster_issuer]] <<input_cluster_issuer,cluster_issuer>>

Description: SSL certificate issuer to use. Usually you would configure this value as `letsencrypt-staging` or `letsencrypt-prod` on your root `*.tf` files.

Type: `string`

Default: `"selfsigned-issuer"`

==== [[input_enable_service_monitor]] <<input_enable_service_monitor,enable_service_monitor>>

Description: Enable Prometheus ServiceMonitor in the Helm chart.

Type: `bool`

Default: `true`

==== [[input_helm_values]] <<input_helm_values,helm_values>>

Description: Helm chart value overrides. They should be passed as a list of HCL structures.

Type: `any`

Default: `[]`

==== [[input_app_autosync]] <<input_app_autosync,app_autosync>>

Description: Automated sync options for the Argo CD Application resource.

Type:
[source,hcl]
----
object({
    allow_empty = optional(bool)
    prune       = optional(bool)
    self_heal   = optional(bool)
  })
----

Default:
[source,json]
----
{
  "allow_empty": false,
  "prune": true,
  "self_heal": true
}
----

==== [[input_dependency_ids]] <<input_dependency_ids,dependency_ids>>

Description: IDs of the other modules on which this module depends on.

Type: `map(string)`

Default: `{}`

==== [[input_namespace_labels]] <<input_namespace_labels,namespace_labels>>

Description: Labels to apply to the destination namespace managed by Argo CD (requires CreateNamespace=true).

Type: `map(string)`

Default:
[source,json]
----
{
  "istio.io/dataplane-mode": "ambient"
}
----

==== [[input_gateway_name]] <<input_gateway_name,gateway_name>>

Description: Name of the Istio Gateway resource to attach the HTTPRoute to.

Type: `string`

Default: `"istio-gateway"`

==== [[input_gateway_namespace]] <<input_gateway_namespace,gateway_namespace>>

Description: Namespace of the Istio Gateway resource.

Type: `string`

Default: `"istio-ingress"`

==== [[input_oidc]] <<input_oidc,oidc>>

Description: OIDC configuration for oauth2-proxy authentication in front of Kafka UI.

Type:
[source,hcl]
----
object({
    issuer_url              = string
    oauth_url               = string
    token_url               = string
    api_url                 = string
    client_id               = string
    client_secret           = string
    oauth2_proxy_extra_args = optional(list(string), [])
  })
----

Default: `null`

==== [[input_allowed_groups]] <<input_allowed_groups,allowed_groups>>

Description: List of Keycloak groups allowed to access Kafka UI. When empty, any authenticated user is allowed.

Type: `list(string)`

Default: `[]`

==== [[input_kafka_username]] <<input_kafka_username,kafka_username>>

Description: Kafka username used by Kafka UI to connect to the broker.

Type: `string`

Default: `"kafka-ui"`

==== [[input_kafka_password_secret_name]] <<input_kafka_password_secret_name,kafka_password_secret_name>>

Description: Name of the Kubernetes Secret containing the Kafka user password generated by Strimzi.

Type: `string`

Default: `"kafka-ui"`

==== [[input_kafka_password_secret_key]] <<input_kafka_password_secret_key,kafka_password_secret_key>>

Description: Secret key that stores the Kafka user password in the Strimzi-generated secret.

Type: `string`

Default: `"password"`

==== [[input_kafka_password_secret_namespace]] <<input_kafka_password_secret_namespace,kafka_password_secret_namespace>>

Description: Namespace where the Strimzi-generated Kafka user secret is stored.

Type: `string`

Default: `"ingestion"`
